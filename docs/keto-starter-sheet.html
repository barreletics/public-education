Keto starter sheet

Print and stick on the fridge. Goal: under 20 grams net carbs per day. Fat is the main calorie source — not a high-protein / carnivore plate.

Simple rule: fat as the main calories · protein moderate (enough to protect muscle) · no carbs or sugar unless it’s an avocado or something that’s mostly fat. Bone broth + butter when eating is hard.

✓ Eat these

  • Eggs, fish, clean meats — moderate, with fat
  • Avocado, olive oil, butter, ghee, MCT
  • Bone broth; add butter if tolerated
  • Spinach, broccoli, cauliflower
  • Cheese, macadamia nuts
  • Water, black coffee, unsweet tea (butter in tea if tolerated)

✗ Skip these

  • Bread, pasta, rice, potatoes
  • Sugar, candy, soda, juice
  • Beer and sweet wine
  • Fruit (avocado is the exception — it’s mostly fat)
  • Chips, crackers, cereal

Track it (pick one)

  • Keto-Mojo meter — measures glucose + ketones → GKI (best proof it's working)
  • Optional app — Carb Manager or Cronometer to count carbs (helpful, not required)
  • Print GKI log sheet — write numbers twice daily
