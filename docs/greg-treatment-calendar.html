How chemo + FBZ cycles usually align

Ask oncologist specifically: "Can we run fenbendazole/ivermectin days 1–4 of each 14-day metabolic cycle, avoiding chemo infusion days if there's interaction risk?"

  • Some patients offset IVM from FBZ by a few hours
  • Some pause antiparasitics 48h before/after infusion until team confirms safety
  • Never self-adjust chemo schedule — only the adjunct cycle
